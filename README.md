# placitum/cookie

Инспектор куки Placitum: выдаёт клиенту подписанную куку, снимает её, пишет её значение в живой
набор и рассказывает об этом соседям. Сам ничего не проверяет и никого не блокирует — по выданной
куке решают другие: локальный слой на краю, автодействия соседей, счётчик.

Проще всего видно на рекламном трафике. Клиент приходит по ссылке с `utm_source=yandex-direct`;
инспектор кладёт ему подписанную куку с меткой источника, пишет значение в живой набор и ставит
на запись маркер `src:yandex-direct`. Кампания видна в журнале без единого похода в приложение, а
край узнаёт этого клиента по набору — без шины и без инспектора.

```
модуль ──► waf.req.cookie ──► cookie ──► allow + Set-Cookie
                                 │
                                 ├── состояние куки: absent | present | invalid | expired
                                 ├── запись значения в живой набор
                                 └── просьбы соседям: маркер, очки
```

## Что нужно знать

- **Вердикта, кроме `allow`, у него нет.** Очки на маршруте он двигает просьбой, которую исполняет
  модуль. Собственные сбои — `verdict: error` с кодом `COOKIE_*`, а не тихий `allow`.
- **Работает на обеих фазах.** На фазе запроса кука ставится до апстрима и видна приложению; на
  фазе ответа виден код ответа — можно не выдавать куку тому, кому апстрим ответил 404.
- **Подпись по умолчанию.** Кука, по которой контур принимает решения, без подписи набирается
  руками в консоли браузера. Подобранное значение — состояние `invalid`, а не «куки нет».
- **Маршрут обязан снимать заголовки** (`waf_capture request headers`): без них куку читать не
  по чему, и ответ — `COOKIE_HEADERS_UNAVAILABLE`.

## Сборка

```sh
docker build -f deploy/Dockerfile -t placitum/cookie .
docker buildx build -f deploy/Dockerfile -t placitum/cookie \
  "https://github.com/exemt/placitum-cookie.git#develop"
```

Ключ подписи, переменные, требования к маршруту и проверка после запуска —
[INSTALL.md](INSTALL.md).

## Ветки

`develop` — то, что разрабатывается: сюда приезжает каждая выкладка. `main` — выкаченные сборки.
Правок в этом репозитории не делают: обе ветки производные от платформы.
